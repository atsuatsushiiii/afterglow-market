# Afterglow Market

A responsive clothing storefront for everyday streetwear, denim, shoes, and accessories.

## Run locally

Requirements: Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Features

- Product browsing with category filters and search
- Favorites and an interactive shopping bag
- Responsive mobile navigation and layouts
- Newsletter signup interface

Product and hero photography is loaded from Unsplash. Checkout is a front-end placeholder and is not connected to payment processing.

## Deployment

GitHub Actions builds and deploys the site to GitHub Pages whenever changes are pushed to `main`.
